# ArbOasis Work Handoff

Repository: `ancientboy/arb-oasis`

Canonical branch: `main`

Before changing or deploying the project:

1. Read the current `main` branch.
2. Read `docs/ARBOASIS_PRODUCT_SPEC.md`.
3. Read `docs/ARBOASIS_ARCHITECTURE.md`.
4. Read `docs/ARBOASIS_ROADMAP.md`.
5. Inspect the existing implementation instead of rebuilding it from scratch.
6. Continue from the next incomplete Roadmap item.
7. Validate the project after changes.
8. Sync persistent changes back to GitHub `main`.
9. Deploy the Site from the current `main` branch.

GitHub remains the source of truth. A Work or deployed Site should not become a separate long-lived source tree.
